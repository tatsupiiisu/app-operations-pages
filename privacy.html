プライバシーポリシー

App Operations (local)（以下「本ツール」）における Google ユーザーデータの取扱いを説明します。本ツールの利用者は開発者本人のみです。

1. アクセスするデータ

Google AdMob API の読み取り専用スコープ https://www.googleapis.com/auth/admob.report により、開発者本人の AdMob アカウントの次の情報にアクセスします。

  • パブリッシャー ID、レポートのタイムゾーン、通貨
  • 対象アプリに絞り込んだ、広告ユニット別・日別のレポート（推定収益、広告リクエスト数、マッチしたリクエスト数、表示回数、クリック数）

AdMob の設定変更・お支払い情報・その他の Google アカウントのデータにはアクセスしません。

2. 利用目的

取得したデータは、開発者本人が自分のアプリの広告収益の推定値と運用状況を確認するために、本人の Mac 上で集計・表示する目的にのみ利用します。

3. 保存

集計済みのレポート値は、開発者本人の Mac 内のローカルファイルにのみ保存します。OAuth の認証情報（リフレッシュトークン等）は macOS の Keychain にのみ保存し、アクセストークンはメモリ内でのみ扱います。外部のサーバーやクラウドには保存しません。

4. 共有・移転

取得したデータを第三者と共有・販売・移転することはありません。広告配信やユーザーのプロファイリング、AI／機械学習モデルの学習には利用しません。本ツールによる Google API から取得した情報の利用と他アプリへの移転は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

5. 削除とアクセスの取り消し

ローカルの保存データは、本ツールのキャッシュファイルと Keychain の項目を削除することで消去できます。Google アカウントからのアクセス許可は Google アカウントのアクセス管理 からいつでも取り消せます。

English summary

App Operations (local) is a read-only tool that runs only on the developer's own Mac and is used only by the developer. With the read-only scope https://www.googleapis.com/auth/admob.report it reads the developer's own AdMob account information (publisher ID, reporting time zone, currency) and daily reports per ad unit for the developer's app (estimated earnings, ad requests, matched requests, impressions, clicks). The data is used only to display the developer's own estimated ad earnings on that Mac, is stored only in local files on that Mac, and OAuth credentials are kept only in the macOS Keychain. The data is never shared, sold or transferred to third parties, and is not used for advertising, profiling or training AI/ML models. App Operations (local)'s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from Google Account permissions.

6. 変更と連絡先

取扱いを変更する場合は本ページを更新します。
